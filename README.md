# 🔐 SecureShare — Encrypted File Sharing System

![SecureShare Preview](secure-share-preview.png)
A secure web-based file sharing system designed to protect files using AES-256 encryption before they are stored or shared.

## 📌 About the Project

SecureShare is a Minor Project developed at Jaypee University of Engineering and Technology, Guna.

The project focuses on secure file handling by encrypting files before they are stored or shared, ensuring that the original file content remains unreadable without the correct decryption key.

## ✨ Current Features

- 🔒 AES-256 file encryption
- 🔓 AES-256 file decryption
- 📁 File selection through a web interface
- 🖥️ Modern security-focused user interface
- ⚡ Client-side encryption prototype
- 🔄 Encrypt → Decrypt workflow

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Web Crypto API
- AES-256
